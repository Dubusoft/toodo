A task is done when its completion criteria, the `criteria` of the task, are met. Toodo checks every kind but `manual` itself, about once a minute: `pr_merged` and `pr_open_ci_green` from the task's pull request, `branch_merged_locally` from the repository (for workspaces with completion `local_merge`, where the task branch is merged into `baseBranch` locally and nothing is pushed), `url` by fetching its target, and `command` by running its target in the task worktree once every criterion but the merge criterion is met, so it can check the work before the merge. Check a `manual` criterion of your task with `check_criterion` once it holds, with evidence (a link, a command and its output, or what you verified). Once every criterion is met, a task whose criteria are all automatic is `done` at once; one with a manual criterion awaits completion (`in_review`) until the user confirms it, so stop there.
