A pull request from the task branch into `baseBranch` moves the task to `in_review`, and its merge completes the task. Toodo notices both at its next pull request check, which runs every minute, so right after a merge the task can still read `in_review` for up to about a minute; that is expected, not a miss. Do not call `complete_task` then; read the task again with `get_task` after a minute. Only a task still `in_review` after that needs a look: for another task, `complete_task` says what blocks it; for your own, call `report_blocker` with what you see.
