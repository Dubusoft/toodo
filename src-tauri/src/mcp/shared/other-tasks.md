Use start_task to record that work begins, with reason and refs identifying its context. Use pause_task with a reason when work stops and resume_task when it can continue. Call conclude_task with a non-empty note when work is not adopted; its dependents stay blocked. A planned task can be concluded without start_task, e.g. an idea that is dropped. If another completed task shipped the work, call conclude_task with outcome "shipped_with" and shipped_with set to that task's id. Remove a dependency with remove_dependency only when the dependent no longer needs that work.
